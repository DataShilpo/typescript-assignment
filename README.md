## TypeScript Assignment

## Assignment Overview
This assignment is about solving problems using TypeScript and Object-Oriented Programming (OOP). It covers the basic concepts of TypeScript that I have learned in Modules 1, 2, and 3. The task had two parts—coding problems and two short blog posts.

## What I Have Worked On
In this assignment, I solved 8 coding problems. These problems helped me practice:

* Basic types and function parameters

* Optional and default parameters

* Union types and type narrowing

* Readonly tuples

* Generics and rest parameters

* Interfaces and array methods

* OOP, classes, and inheritance

* Access modifiers

* Promises and asynchronous functions

I also wrote two blog posts to explain some important TypeScript concepts in simple English.
